# Atlas Gastronomic

Atlas Gastronomic is a gastronomic editorial project focused on rigorously researched, technically reproducible recipes and traceable culinary knowledge.

## Project operating system
- `GEMINI.md` — canonical agent operating instructions.
- `.agents/rules/` — persistent project constraints.
- `.agents/skills/` — repeatable workflows.
- `project-memory/` — durable project state, decisions, tasks and knowledge.
- `standards/` — versioned editorial standards and data contracts.
- `plans/` — roadmap, current plan and audit reports.

## Editorial baseline
The initial canonical baseline is `standards/v1.0.0/`. Read its README and relevant documents before research or recipe development. The original v1.0.0 package is preserved as imported; proposed contract changes must be reviewed and versioned.

## Non-negotiable rule
No recipe may be marked human-approved or published by an agent. Final editorial approval is an explicit human action for the exact content version.
