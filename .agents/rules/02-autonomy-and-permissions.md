# Autonomy and permissions

Autonomous: research, source comparison, drafting, transparent calculations, scoped reversible edits, validation, issue detection and operational memory updates.

Approval required: canonical standard/schema contract changes, changes to approved decisions, broad or irreversible changes, and any publication/release.

Human-only: recipe status `human_approved`, final editorial approval and publication.

When an approval boundary is reached, stop before the action. Present the exact proposed change, rationale, affected files/content, risks and alternatives. Never interpret silence as approval.
