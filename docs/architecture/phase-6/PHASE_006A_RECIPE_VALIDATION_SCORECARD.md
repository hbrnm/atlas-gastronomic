### 1. PRINCIPIU ȘI DESTINAȚIE

Grila de evaluare (*Validation Scorecard*) furnizează cadrul calitativ și cantitativ prin care observatorii sau bucătarii evaluatori notează performanța unei rețete pregătite fizic. Aceasta traduce experiența gastronomică empirică într-un set structurat de date, prevenind aprecierile vagi sau exclusiv subiective.

> [!NOTE]
> Fiecare sesiune fizică de gătit primește un punctaj pe 8 dimensiuni cardinale (scară 1–5), completat de înregistrarea anomaliilor conform unei grile standardizate de severitate.

### 3. RUBRICA DETALIATĂ DE PUNCTAJ (SCARA 1–5)

Fiecare dimensiune este notată de la 1 la 5 conform următoarei grile descriptive:

| Punctaj | Nivel Calitativ | Descriere Operațională |
| :---: | :--- | :--- |
| **5** | **Excelent / Exemplar** | Formularea este impecabilă; execuția curge fără nicio ezitare; timpii și cantitățile corespund perfect realității fizice din bucătărie. |
| **4** | **Foarte Bun (Abatere Minoră)** | Rețeta funcționează conform așteptărilor; apar variații minime legate de arzător sau umiditate, rezolvabile intuitiv fără impact asupra calității finale. |
| **3** | **Acceptabil (Necesită Compensație)** | Există neconcordanțe vizibile (de ex. necesar mai mare de lichid, aluat prea dens sau timp activ subestimat cu 15–25%), ce necesită experiență culinară pentru compensare. |
| **2** | **Deficitar (Risc de Eșec)** | Instrucțiunile conțin goluri majore, timpi nerealist de mici sau proporții problematice, existând un risc considerabil de degradare a preparatului. |
| **1** | **Inacceptabil / Critic** | Rețeta eșuează fizic: ardere, necoacere, cantități complet greșite, imposibilitate de montare sau risc de siguranță alimentară. |

### 4. CRITERII DE APLICARE PE FIECARE DIMENSIUNE

#### D1. Acuratețea Ingredientelor (*Ingredient Accuracy*)
- **5:** Toate ingredientele sunt perfect definite (inclusiv denumiri canonice, tăietură, temperatură de pornire).
- **3:** Denumire ambiguă (de ex. „carne de vită” fără a indica piesa sau tipul de tocare).
- **1:** Ingredient cheie omis din lista declarată sau ingredient solicitat în text fără a fi declarat.

#### D2. Suficiența Cantitativă (*Quantity Sufficiency*)
- **5:** Raportul carne:grăsime:legume:lichid produce consistența perfectă; aluatul atinge hidratarea ideală din cantitățile declarate.
- **3:** Este necesară adăugarea a 20–30% lichid în plus față de volumul declarat pentru a evita uscarea sosului.
- **1:** Deficit sever de lichid ce cauzează ardere sau surplus masiv care transformă sosul într-o ciorbă apoasă.

#### D3. Claritatea Instrucțiunilor (*Instruction Clarity*)
- **5:** Fiecare pas are acțiuni clare, parametri de foc specificați și repere senzoriale precise (*success cues*).
- **3:** Repere senzoriale vagi (de ex. „călește până e gata”), lăsând utilizatorul nesigur cu privire la momentul de oprire.
- **1:** Instrucțiuni contradictorii sau termeni tehnici folosiți incorect.

#### D4. Secvențiere & Dependențe (*Step Sequence & DAG Topology*)
- **5:** Fluxul de lucru este perfect sincronizat: aluatul de paste se odihnește și se întinde exact în fereastra pasivă a fierberii ragù-ului; apa de paste ajunge la clocot exact când sosul este gata.
- **3:** Aluatul este gata prea devreme și riscă să se usuce excesiv, sau sosul se răcește în așteptarea debitării pastelor.
- **1:** Blocaj operațional (de ex. pasul solicită sosul cald înainte de începerea preparării acestuia).

#### D5. Acuratețea Timpilor (*Active & Passive Timing Accuracy*)
- **5:** Timpul activ corespunde unui ritm normal de lucru casnic ($\pm 10\%$); timpul pasiv asigură transformarea colagenului fără scurtături.
- **3:** Timpul activ este subestimat masiv (de ex. tăierea a 3 rădăcinoase brunoise din cuțit durează 20 min, nu 5 min).
- **1:** Timpi nerealist de comprimați care ar duce la carne tare sau aluat nedezvoltat.

#### D6. Compatibilitatea Echipamentelor (*Equipment Suitability*)
- **5:** Caserola recomandată (diametru 24–26 cm, fontă emailată) oferă suprafața optimă de evaporare și distribuție a căldurii; tocătorul și oala de 5 L sunt ideale.
- **3:** Recomandarea unui vas prea mic sau cu fund subțire ce sporește riscul de afumare pe fund.
- **1:** Nespecificarea dimensiunii sau tipului de vas, conducând la eșec termic.

#### D7. Utilizabilitatea Cook Mode (*Cook Mode Usability*)
- **5:** Ecranul este perfect lizibil de la 1 m; contrastul pe fundal întunecat elimină oboseala vizuală; butoanele mari permit avansarea cu degetul sau articulația; temporizatorul pasiv este perceput clar ca ghidaj orientativ.
- **3:** Butoane prea mici pentru manipulare rapidă; necesitatea de a atinge ecranul frecvent din cauza stingerii automate (*display sleep*).
- **1:** Blocaje ale aplicației, pierderea stării la reload sau interfață ilizibilă pe blat.

#### D8. Rezultatul Culinar Final (*Final Culinary Result*)
- **5:** Tagliatelle al dente, rugose, legate perfect în mantecatura cu o peliculă lucioasă de ragù; carnea este fondantă, fără senzație grasă greoaie; zero sos separat pe fundul farfuriei.
- **3:** Sos gustos dar ușor separat de paste sau paste fierte o idee peste al dente; porții neuniforme.
- **1:** Preparat necomestibil (ars, sărat excesiv, pastă cleioasă ruptă sau crudă).

### 5. CLASIFICAREA SEVERITĂȚII CONSTATĂRILOR (FINDING SEVERITY TAXONOMY)

Orice problemă identificată în timpul sesiunii fizice de gătit este înregistrată într-un registru de constatări conform celor 4 niveluri standard:

```
┌──────────────────────────────────────────────────────────────────────────────┐
│                    TAXONOMIA DE SEVERITATE A ANOMALIILOR                     │
├──────────────┬─────────────────────────────┬─────────────────────────────────┤
│ Severitate   │ Definiție                   │ Criteriu de Blocare             │
├──────────────┼─────────────────────────────┼─────────────────────────────────┤
│ CRITIC (P1)  │ • Pericol de siguranță      │ BLOCHEAZĂ CERTIFICAREA REȚETEI  │
│              │ • Eșec ireversibil preparat │ Necesită corecție imediată și   │
│              │ • Blocaj complet de gătit   │ re-testare fizică completă.     │
├──────────────┼─────────────────────────────┼─────────────────────────────────┤
│ MAJOR (P2)   │ • Abatere de timp > 30%     │ REȚINE CERTIFICAREA CONDIDATULUI│
│              │ • Deficit masiv de lichid   │ Necesită corecție de text/date  │
│              │ • Risc de textură alterată  │ înainte de aprobarea finală.    │
├──────────────┼─────────────────────────────┼─────────────────────────────────┤
│ MINOR (P3)   │ • Formulări neclare         │ NU BLOCHEAZĂ CERTIFICAREA       │
│              │ • Ergonomie ecran incomodă  │ Corectat în următorul ciclu     │
│              │ • Ușoară ajustare manuală   │ de rafinare editorială.         │
├──────────────┼─────────────────────────────┼─────────────────────────────────┤
│ RECOMANDARE  │ • Sugestie de optimizare    │ INFORMATIV                      │
│ (ADVISORY/P4)│ • Sfat pentru începători    │ Îmbunătățește experiența de gătit│
└──────────────┴─────────────────────────────┴─────────────────────────────────┘
```

### 6. CRITERII DE CERTIFICARE CULINARĂ A REȚETEI (ACCEPTANCE GATES)

O rețetă testată fizic în bucătărie poate fi propusă Product Owner-ului pentru eticheta **`human_approved`** numai dacă îndeplinește cumulativ următoarele condiții:

1. **Zero constatări de nivel CRITIC (P1)** active.
2. **Zero constatări de nivel MAJOR (P2)** nerezolvate.
3. **Scor mediu ponderat minim de 4,2 / 5,0** pe ansamblul celor 8 dimensiuni.
4. Nicio dimensiune individuală notată sub **3**.
5. Înregistrarea completă a datelor cantitative din fișa de observație (`PHASE_006A_KITCHEN_OBSERVATION_TEMPLATE.md`).
