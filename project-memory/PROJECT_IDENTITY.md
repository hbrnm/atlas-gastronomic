# Project Identity

## Name
Atlas Gastronomic

## Mission
Build a high-quality gastronomic editorial knowledge base and recipe experience grounded in culinary rigor, traceable research, reproducible methods and human editorial accountability.

## Operating choices
- Content format: hybrid.
- Editorial rigor: strict.
- Final approval: human.
- Agent autonomy: high for reversible research, drafting and validation; restricted at canonical and publication boundaries.
- Primary working language: Romanian unless the task specifies otherwise.

## Non-negotiable principles
1. No fabricated sources, citations, quotations, metadata or test results.
2. No claim of cooking/testing without recorded human evidence.
3. Distinguish documented facts, widespread attestation, editorial interpretation and uncertainty.
4. Preserve meaningful regional and historical variation.
5. Recipes must be technically executable and reproducible.
6. Automated validation never replaces human editorial approval.
7. No autonomous approval or publication.
