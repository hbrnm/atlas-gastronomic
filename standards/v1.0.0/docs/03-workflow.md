# Flux editorial

## Flux standard
1. **Intake:** se înregistrează denumirea, categoria, aria culinară și scopul.
2. **Scoping:** se definește ce trebuie stabilit: versiune canonică, regională, istorică sau adaptare.
3. **Research:** se colectează surse și se construiește matricea afirmație–sursă.
4. **Synthesis:** se identifică nucleul comun și divergențele.
5. **Draft:** se redactează rețeta în formatul standard.
6. **Technical review:** se verifică proporțiile, randamentul, tehnica, echipamentul, timpii și temperaturile.
7. **Editorial review:** se verifică limba, claritatea, tonul și structura.
8. **Human approval:** editorul aprobă sau respinge versiunea exactă.
9. **Publication:** numai după aprobare.
10. **Maintenance:** se înregistrează corecții, surse noi și versiuni ulterioare.

## Statusuri
- `idea`: înregistrată, necercetată;
- `researching`: cercetare în desfășurare;
- `draft`: propunere redactată;
- `technical_review`: verificare gastronomică/tehnică;
- `editorial_review`: verificare editorială;
- `needs_revision`: necesită modificări;
- `human_approved`: aprobată explicit de editor;
- `published`: publicată;
- `archived`: retrasă sau înlocuită.

## Regula de versionare
Orice modificare de ingredient structural, cantitate, tehnică, temperatură, randament, afirmație de origine sau siguranță creează o versiune nouă. Corecturile minore de ortografie pot fi înregistrate ca patch, dar nu trebuie să schimbe sensul.

## Checklist înainte de aprobare
- [ ] Identitatea preparatului este clară.
- [ ] Afirmațiile istorice/geografice au suport.
- [ ] Ingredientele sunt complete și normalizate.
- [ ] Cantitățile și unitățile sunt explicite.
- [ ] Randamentul este clar.
- [ ] Pașii sunt în ordine logică.
- [ ] Există repere observabile de reușită.
- [ ] Timpii și temperaturile sunt plauzibile.
- [ ] Alergenii sunt identificați.
- [ ] Păstrarea și siguranța sunt tratate când este necesar.
- [ ] Valorile nutriționale sunt etichetate ca estimări și au metodă.
- [ ] Sursele sunt verificabile.
- [ ] Versiunea exactă a fost aprobată de un om.
